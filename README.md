## 📌 Описание проекта
**FinCalc** — это комплексный учебный проект мобильного приложения, разработанный на основе методологии **UML** для управления автомобильными и личными расходами, планирования обслуживания (ТО), а также интеграции ИИ-ассистента.

Система реализует клиент-серверную архитектуру с использованием **Firebase** для хранения данных и обеспечивает безопасное взаимодействие с внешним сервисом **Gemini API**. Вся разработка (кодирование и тестирование) велась в соответствии с разработанной UML-моделью.

<a id="goals"></a>
## 🎯 Цели проекта
1.  Получить практические навыки в **объектно-ориентированном проектировании** и применении **паттернов проектирования**.
2.  Автоматизировать сложные расчеты (топливо, электричество, тормозной путь) через иерархию классов `Calculation`.
3.  Создать эффективную систему **уведомлений и напоминаний** (`Reminder`) о ключевых событиях.
4.  Обеспечить безопасную интеграцию ИИ-ассистента для обработки запросов пользователя.
5.  Провести полное **тестирование** проекта, включая разработку **Test Plan** и Use Case-сценариев.

<a id="features"></a>
## ⚙️ Основные возможности
Функционал проекта охватывает следующие области:
1.  **Управление финансами:** Учет, редактирование и удаление записей расхода (`Expense`), просмотр финансовой статистики (`Financials`).
2.  **Автомобильный менеджмент:** Управление данными авто (`Car`), документами (`Document`) и формирование сводок (`Summary`).
3.  **Специализированные расчеты:** Калькуляторы расхода топлива, электроэнергии, алкоголя, а также расчет тормозного пути и планирование маршрута.
4.  **Планирование:** Создание и управление жизненным циклом напоминаний (`Reminder`).
5.  **ИИ-Ассистент:** Отправка запросов в Gemini API и логирование диалогов (`AIChatRecord`).
6.  **Системные функции:** Просмотр/очистка истории действий (`History`), настройка языка и темы приложения (`UserSettings`).

<a id="uml-documentation"></a>
## 📐 UML-Моделирование и Архитектура
В рамках проектирования были разработаны следующие артефакты:

* **Диаграмма вариантов использования (Use Case) и Сценарии:** Определены все функциональные требования и подробно описаны потоки событий для каждого варианта использования.
* **Глоссарий:** Определены ключевые термины предметной области (`Расчет`, `Логист`, `Тормозной путь`, `BAC`).
* **Диаграмма классов:** Детальная модель, включая иерархию наследования (`Calculation` и его наследники), ключевые сущности (`Expense`, `Reminder`, `AIChatRecord`) и все необходимые методы/атрибуты.
* **Диаграммы компонентов:** Моделирование архитектуры с использованием **интерфейсов** (`IUserEvents`, `IViewData`) для демонстрации принципа **Инверсии Зависимостей**.
* **Диаграмма развёртывания:** Моделирование физического размещения программных компонентов на реальных узлах (`Android Device`, `Firebase`, `Gemini API`).
* **Диаграммы активностей:** Визуализация потоков управления для ключевых сценариев.
* **Диаграммы состояний:** Моделирование жизненного цикла объекта `Reminder` и состояний пользовательского интерфейса калькуляторов.
* **Диаграммы последовательности:** Детализация взаимодействия объектов, включая **безопасную интеграцию ИИ** через прокси-логику Firebase Functions.
* **Документирование паттернов:** Описание примененных паттернов проектирования.

<a id="technologies"></a>
## 🚀 Технологии и Среда
* **Архитектура:** Клиент-серверная (MVVM/MVC, с использованием Firebase Functions как прокси-сервера).
* **База данных/Сервис:** Google Firebase (для хранения данных и аутентификации).
* **Внешние API:** Gemini API (ИИ-ассистент).
* **Система контроля версий:** Git + GitHub.
* **Документирование:** UML (Visio/Mermaid), текстовый редактор.
