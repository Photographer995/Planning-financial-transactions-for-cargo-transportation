## 📌 Описание проекта
 Planning Financial Transactions for Cargo Transportation — это учебный проект, представляющий собой калькулятор для логистов, работающих с международными перевозками.  
Программа помогает рассчитывать затраты на рейс, конвертировать валюты, учитывать дополнительные расходы (топливо, пошлины, налоги и т.д) и формировать отчёты.

<a id="goals"></a>
## 🎯 Цели проекта
1. Автоматизировать расчёт стоимости перевозки.  
2. Упростить планирование финансовых операций для логиста.  
3. Повысить точность и скорость подготовки финансовых отчётов.  
4. Дать удобный инструмент для анализа затрат.

<a id="features"></a>
## ⚙️ Основные возможности
1. Учёт валютных курсов и автоматическая конвертация.  
2. Расчёт ключевых статей расходов: топливо, пошлины, налоги.   
3. Формирование финансовых отчётов.
