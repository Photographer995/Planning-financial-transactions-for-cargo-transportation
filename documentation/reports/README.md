# 📁 Тестирование 

Этот раздел обеспечивает документальное подтверждение стабильности, надежности и соответствия функционала **FinLogCalc** установленным требованиям. Материалы в этой директории отражают системный подход к тестированию и служат основой для оценки качества продукта перед релизом.

### 📊 Содержание раздела

| Файл | Описание | Роль в проекте |
|:---|:---|:---|
| **`Test_Plan.docx`** | Стратегия обеспечения качества. Содержит цели, область тестирования, ресурсы, методологию и критерии завершения. | Является **дорожной картой** проверки соответствия функциональных и нефункциональных требований. |
| **`Test_Results_Template.docx`** | Шаблон для фиксации результатов тестирования и регистрации дефектов. | Обеспечивает **единообразие** оформления баг-репортов и **прозрачность** процесса тестирования. |
