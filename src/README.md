# 📱 Исходный код приложения

Исходный код для проекта FinLogCalc загружен и находится в ветке master репозитория на GitHub.

## 🎯 Кодовая база FinLogCalc

**Язык:** Kotlin  
**Платформа:** Android  
**Архитектура:** MVVM / Clean Architecture

### 🗂️ Структура проекта
```
app/
├── 🛡️ auth/ # Модуль аутентификации и авторизации
├── 🧮 calculator/ # Модуль финансовых расчетов
├── ⚡ features/ # Общие компоненты и дополнительные функции
├── 🚗 mycar/ # Модуль учета автомобильных расходов
├️── 📻 radio/ # Модуль медиа-плеера и радио
├── 🎨 ui/ # Общие UI компоненты и темы
├── 🔧 utils/ # Вспомогательные утилиты и ИИ помошник
├── 📱 MainActivity.kt # Главная активность приложения
└── ⚙️ SettingsScreen.kt # Экран настроек и конфигурации
```

**Статус:** ✅ Рабочий код | **Версия:** 2.7H
