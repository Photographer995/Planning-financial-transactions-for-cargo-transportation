# 📊 Диаграммы и модели проекта

### 📋 Обзор диаграмм

| Файл | Тип диаграммы | Описание |
|:---|:---|:---|
| **`Use Cases.pdf`** | Use Case | Сценарии использования приложения |
| **`Диаграмма классов.pdf`** | Class Diagram | Структура классов и их взаимосвязи |
| **`Диаграмма компонентов.pdf`** | Component Diagram | Архитектурные компоненты системы |
| **`Диаграмма развёртывания.pdf`** | Deployment Diagram | Развертывание приложения на устройствах |
| **`Диаграммы последовательности.prog`** | Sequence Diagram | Взаимодействие объектов во времени |
| **`Диаграмма активности истории.pdf`** | Activity Diagram | Бизнес-процесс работы с историей |
| **`Диаграмма активности калькуляторов.pdf`** | Activity Diagram | Логика работы калькуляторов |
| **`Диаграмма состояния Калькулятора.pdf`** | Statechart | Состояния калькулятора |
| **`Диаграмма состояния Уведомления.pdf`** | Statechart | Жизненный цикл уведомлений |
| **`Описание сценариев.pdf`** | Text | Детальное описание use case сценариев |


## 🎯 Назначение раздела

Данные диаграммы представляют **полный UML-пакет** проекта, охватывающий все аспекты системы:

- **📋 Use Case** - взаимодействие пользователя с системой
- **🏗️ Class/Component** - статическая структура приложения  
- **🔄 Sequence/Activity** - динамическое поведение
- **📱 Deployment** - физическое развертывание
- **🔄 Statechart** - управление состояниями объектов


**Статус:** ✅ Полный комплект UML | **Назначение:** 🎯 Архитектурное проектирование
